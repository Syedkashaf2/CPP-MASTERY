###### **5. Diagnostic Challenge #1 (H0 — Probe R-013)**

Problem Statement

You are given a binary array nums (containing only 0s and 1s) and a non-negative integer k. Return the maximum number of consecutive elements you can select from nums such that the selected contiguous subarray contains at most k zeros.



###### **Function Signature (C++17)**



```cpp

#include <vector>



int longestOnesWithAtMostKZeros(const std::vector<int>\& nums, int k);

```



###### **Input / Output Contract \& Constraints**

* 0 <= nums.size() <= 100,000
* Each element nums\[i] is either 0 or 1.
* 0 <= k <= nums.size()
* If no non-empty contiguous subarray satisfies the condition (for example, when nums is empty, or when k == 0 and every element in nums is 0), return 0.
* Target Efficiency: $O(N)$ time complexity and $O(1)$ auxiliary space complexity.



###### **Examples**



* **Example 1:** nums = {1, 1, 0, 1, 1, 1, 0, 1}, k = 1 -> Output: 6 (the subarray {1, 1, 0, 1, 1, 1} has length 6 and contains 1 zero).   
* **Example 2:** nums = {0, 0, 0}, k = 0 -> Output: 0.
* **Example 3:** nums = {1, 0, 1, 1}, k = 2 -> Output: 4.
